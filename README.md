# LaserGRBL Mobile

LaserGRBL Mobile 是一个面向 Android 手机的 GRBL / 激光雕刻机上位机。它的目标是让手机通过 USB OTG 串口直接连接 GRBL 主控，把手机当作便携控制端来完成连接、状态监控、手动移动、G-code 文件读取、图片 / SVG 转 G-code、轨迹预览和任务发送。

这个项目参考了 PC 端 LaserGRBL 的使用场景，但不是 LaserGRBL 官方移动版，也不是对 PC 端界面的简单复制。移动端的重点是：现场能用、界面紧凑、安全确认明确、串口发送稳定。

> 当前阶段还没有真实雕刻机硬件验证，已经完成本地单元测试、Debug APK 构建和 GitHub Actions 自动构建。首次实测请务必低功率、空载，最好先拔掉激光头或关闭激光使能，只验证串口、状态查询和移动控制。

- 应用名称：LaserGRBL Mobile
- 包名：`com.x.lasergrbl_mobile`
- 最低系统：Android 10，`minSdk 29`
- 目标系统：Android 16 / SDK 36，`targetSdk 36`
- 串口方式：USB OTG + USB Serial
- 默认波特率：`115200`，连接页支持手动输入自定义波特率
- 当前构建产物：Debug APK
- 自动发布：push 后 GitHub Actions 自动测试、构建并发布 APK 到 Release 资产
- 转换功能：支持图片栅格转换、SVG path / 基础图形 / 贝塞尔曲线 / 圆弧 / 颜色层转换为 GRBL 激光 G-code

## 主要功能

### USB 串口连接

- 扫描手机当前可见的 USB 串口设备。
- 支持常见 USB 串口芯片和 CDC 设备，依赖 `usb-serial-for-android`。
- 支持 Android USB 权限请求。
- 连接后持续读取串口输出，按行解析 GRBL 响应。
- 默认串口参数：
  - `115200 baud`
  - `8N1`
  - 无流控
- 默认推荐 `115200`，如果遇到特殊固件或旧控制板，可以在连接页手动输入其他波特率。

常见可支持设备类型包括：

- CH340 / CH341
- CP210x
- FTDI
- CDC ACM
- 其他由 `usb-serial-for-android` 支持的 USB Serial 设备

### GRBL 状态监控

支持解析 GRBL 状态上报，例如：

```text
<Idle|MPos:0.000,0.000,0.000|FS:0,0>
<Run|WPos:10.000,5.000,0.000|FS:1200,255>
```

界面会显示：

- 当前状态：`Idle`、`Run`、`Hold`、`Jog`、`Alarm` 等
- 机器坐标 `MPos`
- 工件坐标 `WPos`
- 进给速度
- 激光 / 主轴值
- 原始串口日志

### 常用 GRBL 控制

内置常用按钮：

- 查询状态：`?`
- 解锁：`$X`
- 回零：`$H`
- 软复位：`Ctrl-X`
- 暂停：`!`
- 继续：`~`
- 关光：`M5`

这些按钮尽量保持一键可用，方便现场快速操作。

### Jog 手动移动

支持基础 Jog 控制：

- `X-`
- `X+`
- `Y-`
- `Y+`
- `Z-`
- `Z+`

支持步长：

- `0.1 mm`
- `1.0 mm`
- `10.0 mm`

发送格式类似：

```text
$J=G91 G21 X+1.000 F1200
```

### 激光弱光测试

支持发送：

```text
M3 S{power}
```

界面中可以调整 `S1 ~ S1000` 的弱光测试值。

注意：不同 GRBL 固件和激光模块对 `S` 值映射不同，第一次测试必须使用低功率。

### G-code 文件读取与图片转换

支持通过 Android 文件选择器读取本地文件：

- `.nc`
- `.gcode`
- `.txt`
- 其他文本形式 G-code
- 常见图片文件，例如 `.png`、`.jpg`、`.jpeg`
- 基础 SVG 文件

读取 G-code 后会：

- 去除 `;` 注释
- 去除括号注释 `(comment)`
- 丢弃空行
- 统计有效 G-code 行数
- 估算 XY/Z 运动范围
- 显示文件名和任务概况

读取图片后会：

- 解码图片并转换为灰度图
- 自动缩放过大的图片，避免手机内存和 G-code 行数失控
- 按设定宽度生成物理加工尺寸
- 按设定行距生成栅格扫描线
- 使用 `M4 S...` 动态功率模式生成激光功率
- 使用 `M5` 在空白区关光
- 支持材料参数预设
- 支持 Gamma 灰度曲线
- 支持有序抖动和误差扩散抖动
- 支持横向 / 纵向扫描方向
- 支持双向扫描，减少空程移动
- 支持反相雕刻
- 支持最大功率、阈值、雕刻进给、空程进给设置
- 转换完成后直接进入同一个任务发送流程

图片转换生成的 G-code 会包含类似内容：

```text
G21
G90
M5
G0 X0.000 Y0.000 F3000
M4 S350
G1 X0.000 Y0.000 S350 F1200
M5
```

默认图片转换参数偏保守，主要用于首次硬件验证：

- 宽度：`30 mm`
- 行距：`0.12 mm`
- 雕刻进给：`F1200`
- 空程进给：`F3000`
- 最大功率：`S350`
- 阈值：`18`

不同机器的激光功率、材料响应、焦距和 GRBL 配置差异很大，图片转换结果不能直接当成最终加工参数。首次测试建议从低功率、小尺寸、废料开始。

当前内置材料预设包括：

- 自定义
- 椴木
- 纸板
- 皮革
- 阳极铝

这些预设只是起点，用于快速带出一组较合理的行距、进给、功率、阈值、Gamma 和抖动设置；实际加工仍要按机器、材料和焦距微调。

读取 SVG 后会：

- 解析 SVG XML 节点，而不是只用字符串提取 path
- 支持 `<path d="...">`
- 支持 `M`、`L`、`H`、`V`、`Z` 基础线段命令
- 支持 `C`、`S`、`Q`、`T` 贝塞尔曲线命令，并自动展平为可雕刻线段
- 支持 `A` / `a` SVG path 椭圆弧命令，并自动展平为可雕刻线段
- 支持 `<rect>`、`<circle>`、`<ellipse>`、`<polyline>`、`<polygon>` 基础图形
- 支持常见 `transform`：`matrix`、`translate`、`scale`、`rotate`、`skewX`、`skewY`
- 支持 `<g>` 分组和子节点继承 transform
- 支持按 `stroke` / `fill` 颜色自动分层
- 支持继承父级 `<g>` 的颜色和样式
- 支持跳过 `display:none`、`visibility:hidden`、透明或 `fill/stroke:none` 的不可见对象
- 颜色分层开启时，会按颜色层分组输出，并给不同颜色层设置独立功率和进给
- 支持手动图层参数表：默认/黑、红、蓝、绿、黄/橙、其他
- 每个颜色类别都可以单独启用或跳过，并调整 `S` 功率和 `F` 进给
- 支持相对坐标和绝对坐标
- 按设定宽度缩放到实际加工尺寸
- 生成 `G0` 空程、`M4 S...` 开光、`G1` 线段雕刻、`M5` 关光
- 记录跳过的暂不支持 path 命令，方便排查复杂 SVG

SVG 转换适合简单 logo、线稿、外框和常见矢量图形。贝塞尔曲线和 SVG path 圆弧会展平成多段 `G1`，圆形和椭圆会近似为多边形路径。颜色分层默认开启，图层表提供默认/黑、红、蓝、绿、黄/橙、其他几类；用户可以按材料需求单独启用或跳过某类颜色，并调整该类的功率和进给。复杂 SVG 仍建议先在矢量软件里检查尺寸、删除隐藏对象，并用边界预跑确认实际范围。

### 轨迹预览

当前版本提供轻量级 2D 轨迹预览：

- 解析 `G0/G1`
- 提取 `X/Y`
- 估算边界
- 在手机界面中绘制简易路径
- 对带 `S` 功率的 `G1` 线段按功率强弱调整显示深浅

这不是完整 CNC 仿真器，也不会模拟圆弧、激光功率、材料效果。它的目标是让用户在发送前粗略确认文件范围和路径方向。

### G-code 流式发送

当前采用稳定优先的单行发送策略：

1. 发送一行 G-code
2. 等待 GRBL 返回 `ok` / `error` / `ALARM`
3. 收到确认后发送下一行

优点：

- 简单稳定
- 易于定位错误行
- 适合首次实机测试

缺点：

- 速度比 PC 端成熟 sender 的缓冲流式发送慢

后续可以升级为 GRBL character-counting streaming，更充分利用 GRBL 接收缓冲区。

### 任务控制

任务发送页提供：

- 开始
- 边界预跑
- 暂停
- 继续
- 停止
- 当前行显示
- 已确认行数
- 错误计数
- 进度条
- 安全确认复选框

开始按钮会根据状态变化：

- 未连接串口或没有任务时，开始按钮不可点击。
- 已连接且已有任务，但没有勾选安全确认时，点击开始会弹出安全提醒 Toast，不会启动任务。
- 勾选安全确认后点击开始，会先显示 `请等待3秒`、`请等待2秒`、`请等待1秒` 的倒计时。
- 倒计时结束后才真正开始发送任务。
- 任务发送中，主按钮会变为红色 `停止`，可以直接停止当前任务。

### 边界框预跑

任务发送页支持边界框预跑。应用会根据已加载任务的 XY 运动范围生成一组 `M5`、`G21`、`G90` 和 `G1` 命令，让机器在激光关闭状态下按手动移动进给速度绕任务外框移动一圈。

边界预跑会：

- 要求已连接串口
- 要求已加载有效任务
- 要求任务存在有效 XY 范围
- 要求勾选安全确认
- 通过同一个一行一确认发送流程执行
- 全程保持 `M5` 关光，不生成 `M3/M4` 开光命令

注意：边界框基于当前解析到的 XY 坐标估算，不能替代完整 CNC 仿真。运行前仍需确认机器原点、工件坐标、行程和夹具位置。

### 手动命令

提供手动命令输入框，可以直接发送：

```text
$$
$I
$X
G0 X0 Y0
M5
```

也可以发送实时指令：

- `!`
- `~`
- `?`

## 界面设计

界面是中文优先，布局紧凑，分为几个页面：

- 连接
- 控制
- 文件
- 发送
- 设置
- 日志
- 关于

支持系统、浅色、深色三种主题模式。默认使用系统模式，跟随手机系统当前的深色 / 浅色主题；如果用户在系统控制中心切换主题，应用会随当前系统主题变化。主题没有使用随机动态色，避免浅色深色切换后文字对比度不可控。

转换参数里的按钮、滑块、复选框和说明文字都使用 Material3 主题颜色，不写死亮色或暗色。新增的 SVG 颜色分层开关和图层参数表会跟随当前浅色 / 深色主题切换，控件和文字颜色与其他转换参数保持一致。

关于页提供仓库、Issues、Pull Requests 和 Releases / APK 页面入口，方便用户反馈问题和下载构建产物。

## 安全提示

激光雕刻机有现实风险，不要把它当成普通串口玩具。

首次实测建议：

1. 不装激光头，或关闭激光电源。
2. 手机连接 OTG，再连接雕刻机 USB。
3. 打开 App，刷新设备，连接串口。
4. 先观察 GRBL 启动信息。
5. 点击 `查询 ?`，确认能收到状态。
6. 点击 `$X` 解锁。
7. 用 `0.1 mm` 步长测试 X/Y Jog。
8. 确认方向和限位没问题后，再测试 `M5`、弱光。
9. 最后再加载很小的 G-code 文件做空跑。

开始真实雕刻前必须确认：

- 护目镜
- 防火
- 急停
- 材料固定
- 机器行程
- G-code 尺寸和原点
- 激光功率

## 当前限制

- 尚未完成真实硬件测试。
- 当前只支持 USB OTG 串口，不支持蓝牙或 Wi-Fi 串口桥。
- 当前 G-code 流式发送是保守的一行一确认策略。
- 当前轨迹预览只覆盖基础 `G0/G1`，不完整模拟圆弧和雕刻效果。
- 已支持基础图片栅格转 G-code。
- SVG 转换已支持常见 path、基础图形、贝塞尔曲线展平、path 圆弧展平、颜色分层、手动图层参数和常见 transform，但不会处理外部 CSS 文件、复杂选择器、填充区域扫描和布尔运算。
- 已内置一组图片转换材料预设，但仍需要按机器和材料实测微调。
- 已支持加工前边界框预跑，但不能替代完整仿真。

## 项目定位

LaserGRBL Mobile 的目标不是替代所有 PC 端专业软件，而是在手机上提供一个足够安全、紧凑、可用的 GRBL 控制和发送工具。它更适合现场调试、轻量加工、临时移动控制和没有电脑时的应急使用。
